# DiscordMinecraftBot

Arayuzlu Discord botu.

## Ozellikler

- Windows GUI
- Bot baslat/durdur
- Token ve ayar kaydetme
- Spam algilama
- Otomatik mute
- Manuel !mute / !unmute
- !ping
- Canli log ekrani

## Kurulum

1. Python 3.11+ kur.
2. `install.bat` dosyasini calistir.
3. `bot.py` ile arayuzu ac.
4. Discord Developer Portal'dan bot tokenini gir.
5. BOTU BASLAT'a bas.

## EXE

`build_exe.bat` calistirildiginda `dist/DiscordMinecraftBot.exe` olusur.

Token GitHub'a yuklenmez; `config.json` .gitignore icindedir.

## Komutlar

`!ping`

`!mute @kullanici 120`

`!unmute @kullanici`

Mute komutlari Discord'da Manage Messages yetkisi ister.
